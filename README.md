# Тратомер

Учёт личных ежедневных расходов. Одна страница, без сервера и аккаунтов:
записи лежат в браузере устройства (localStorage).

**Приложение:** https://vovamscvk-dot.github.io/Tratomer/

## На телефон

Откройте ссылку и добавьте на главный экран:
- **Android / Chrome** — меню «⋮» → «Установить приложение»
- **iPhone / Safari** — «Поделиться» → «На экран «Домой»»

Дальше работает офлайн и открывается без адресной строки.

## Данные

Хранятся только на устройстве и никуда не отправляются. Между телефоном и
компьютером не синхронизируются — это разные хранилища.

Чистка браузера стирает записи, поэтому в разделе «Операции» есть
**«Скачать копию»** (файл JSON) и **«Восстановить»**. Импорт проверяет каждую
запись и пропускает дубли, так что восстанавливать можно поверх существующих трат.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html` | всё приложение — разметка, стили, логика |
| `sw.js` | service worker: офлайн-режим, сеть в приоритете |
| `manifest.webmanifest` | имя, иконки, режим запуска |
| `make-icon.js` | генератор иконок (`node make-icon.js`), без зависимостей |

При выкладке новой версии поднимите `VERSION` в `sw.js`, иначе у уже
установивших приложение останется старый кэш.
